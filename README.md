# Expense Management System

A modular console-based Expense Management System developed in Python using Object-Oriented Programming principles.

## Features

### Expense Management
- Add Expense
- View All Expenses
- Search by Category
- Search by Date
- Update Expense
- Delete Expense

### Data Persistence
- JSON File Storage
- Automatic Load and Save
- UUID based Expense Identification

### Statistics
- Total Number of Records
- Total Amount Spent
- Highest Expense
- Lowest Expense
- Average Expense
- Category-wise Summary
- Payment Method-wise Summary
- Monthly Spending Summary

### Charts
- Category-wise Expense Chart
- Payment Method-wise Expense Chart
- Monthly Spending Trend

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- JSON
- Matplotlib
